# Tarkov News Dashboard

A personal, always-current dashboard for Escape from Tarkov news, hosted on GitHub Pages.

- **Today's Briefing** — an AI-generated summary of what changed across patch notes, the market, and the community in the last 24 hours, refreshed every morning.
- **Updates Today** — a lightweight, timestamped feed of anything urgent that drops during the day.

Content is generated by a Claude Code scheduled task running on the owner's machine (not GitHub Actions), which writes to [`data/briefing.json`](data/briefing.json) and pushes it here. The page itself is static HTML/CSS/JS that reads that file — no backend, no database.

Sources: r/EscapefromTarkov, the official Tarkov patch notes page, the [tarkov.dev](https://tarkov.dev) API, and the EFT Wiki recent changes feed.
